# GT Neo2 Tint Camera

A clean rebuild based on an open-source Android camera foundation. The project adds a real Tint control from -100 to +100 to the camera preview and recording pipeline.

Base project direction: Camera2/OpenGL real-time filtering. CameraView is a documented open-source Android camera library supporting Camera2, video capture and real-time filters. citeturn0search0

Target device: realme GT Neo2 (RMX3370).
